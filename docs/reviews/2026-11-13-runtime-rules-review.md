## 范围与退出条件

用户授权只把后台受托运行、结构化输出保证程度、时限和预算的通用规则补到规范，具体实现与 ServerAgent 业务分开，暂不开发，补完后独立评审。本轮不采用完整消费者清单为 SDK 支持承诺，不改原始期望清单、ServerAgent 协议、源码或历史评审。

同一能力路径：可信应用/服务在当前有效授权下提供任务、产出要求和运行限制 → 受支持 Agent/交互 → 实际内容、保证/校验状态、终态及用量/停止证据 → 原应用按业务权限验证和消费。写入时保留原 owner 防重与读回，纯生成不强行增加工具。退出条件是通用语义明确且语言无关、原安全/产品目标不降级、未参与编写的独立角色与裁判关闭实质问题、文档链接/版本/基线检查通过；运行验收只定义不执行。

权限/披露及费用承诺按高风险语义审查。沿用原授权、原生记忆、业务效果/恢复/账本 owner，不增加委托中心、维护队列或新状态平台；没有代码、迁移、部署及发布变更，不运行真实模型或业务。用同一证据记录承接标准、修订和反例，必要负例不能以减少文档为由省略；无新实质证据不扩展同类审查。
